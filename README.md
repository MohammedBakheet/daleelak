# دليلك

نسخة أولية بسيطة لبوابة التقاويم الرقمية، بهوية مستوحاة من العمارة السلمانية.

## النشر على GitHub Pages
1. أنشئ مستودعًا عامًا في حساب MohammedBakheet.
2. يفضّل اسم `daleelak` لضمان رابط واضح.
3. ارفع الملفات إلى جذر المستودع.
4. من Settings → Pages اختر Deploy from a branch ثم main و / (root).

الرابط المتوقع: https://MohammedBakheet.github.io/daleelak/

ملاحظة: ملف demo-calendar.ics تجريبي فقط.

إعداد وإدارة: محمد البخيت
