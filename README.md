# دليلك — الإصدار التأسيسي للتصنيفات

التصنيفات الرئيسية المعتمدة:

1. التعليم العام (`general-education`)
2. التعليم الجامعي (`higher-education`)
3. الرياضة (`sports`)
4. المناسبات (`occasions`)

## إضافة تصنيف جديد لاحقًا

يُضاف سجل واحد فقط إلى `data/categories.json`. لا يلزم إنشاء صفحة HTML جديدة؛ إذ تستخدم جميع التصنيفات الصفحة الديناميكية:

`category.html?id=category-id`

## إضافة تقويم جديد

1. إنشاء مجلد داخل `calendars/`.
2. إضافة `info.json` و`calendar.ics`.
3. استخدام معرّف التصنيف الصحيح في `info.json`.
4. إضافة مسار `info.json` إلى `data/catalog.json`.

## تحديث تقويم قائم

استبدل `calendar.ics` فقط إذا لم تتغير بيانات البطاقة. حدّث `info.json` عند تغيير السنة أو الوصف أو تاريخ التحديث.
